# Sprint Archive: v0.33.3

## 🚀 Released v0.33.3 (Stability & BEM Hotfixes)
- [x] **Veo S2E Spinner Freeze**: Fixed UI state race condition in `ClipsView.tsx` where background auto-saves overwrote the optimistic 'Generating' status before Kie remote `taskId` returned, effectively aborting the frontend polling loop.
- [x] **BEM Pool Unlinking Cascade**: Fixed bug where unlinking an image from the BEM Asset Pool implicitly assumed `isResult=true` for former results, causing the backend `/api/media/unlink` to wipe the actively displaying result video. Hardcoded `isResult=false`.
- [x] **ActionToolbar Layout Restoration**: Restored inline flex alignments spanning Episode, Sideload, and View modes that were inadvertently broken during previous layout refactors.
- **BEM Viewport Context**: Fixed rendering visibility bugs for the "Latest Result" viewer by re-supplying strict `viewportContext` conditionals.
